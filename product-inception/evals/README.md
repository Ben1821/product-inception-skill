# Product Inception 行為評估

使用 [cases.json](cases.json) 在 Claude Code、Codex 或其他支援 Agent Skills 的工具中評估輸出行為。每個案例包含可直接輸入的提示、應觀察的行為，以及會讓該案例失敗的錯誤。案例中的設定和數字均為測試資料。

1. 在測試專案安裝 Skill，確認呼叫的是本次版本（Claude Code 為 `/product-inception`，Codex 為 `$product-inception`）。以每案一個新對話執行，避免前一案的內容影響結果。
2. 手動測試在首輪提示前加上上述呼叫指令。如案例有後續訊息，逐輪輸入，並在指定的輪次檢查行為。
3. 逐項記錄是否達成，附回覆摘錄或工具行為作為證據。應觀察的行為都達成且無任一失敗行為，案例才通過。以具體行為評估，措辭、順序、圖表和模板可因情境調整。
4. 若要對比版本，在相同模型、工具、案例及對話條件下另開新對話。要檢查自動觸發時，用同一個案例另開新對話並省略斜線指令，查閱實際 Skill 呼叫紀錄。

記錄欄位可用「Skill 版本｜模型及工具版本｜案例｜結果｜證據｜下次調整」。案例供人工評估，毋須測試套件。
